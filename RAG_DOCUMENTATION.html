1. Executive Summary

Masar AI is a serverless Retrieval-Augmented Generation (RAG) assistant delivering domain-specific career and interview advisory. The system is built end-to-end on Cloudflare serverless edge infrastructure, achieving instantaneous cold starts, global edge caching, and zero recurring infrastructure costs.

4. Key Engineering Decisions

Hierarchical Semantic Chunking vs. Naive Windows

Standard sliding-window chunkers cut text arbitrarily every 200–300 words. This breaks interview scripts, counter-offer dialogues, and STAR framework steps across arbitrary vector boundaries.

Solution: The custom ingestion chunker detects true section-heading boundaries (^\d+\.\s+([A-Z].*)), preserves lists and paragraphs intact, and prepends every chunk with breadcrumb metadata: 

Document: {Title} | Section: {Section Name} (Pages {Range})
{Chunk Body Text}

Two-Stage Retrieval (Bi-Encoder + Cross-Encoder)

Bi-encoder retrieval (Vectorize) quickly identifies the top 20 candidate matches in under 15ms. To eliminate false-positive semantic matches, candidates pass through the bge-reranker-base cross-encoder, which joint-encodes the query and text to measure calibrated relevance probabilities. Only the top 4 verified chunks are injected into the prompt.

Cross-Language Query Bridge

When queries are submitted in Arabic, an edge LLM step reformulates the question into dense English retrieval keywords using the Chat Messages API. This ensures accurate vector matching against the English playbook corpus while the final response is generated in the user's native language.

High-Availability LLM Fallback Chain

To prevent service disruption from transient cloud rate limits, the worker automatically cascades through a resilient model fallback chain:

  1. @cf/meta/llama-3.1-8b-instruct-fp8 (Primary)
  2. @cf/meta/llama-3.3-70b-instruct-fp8-fast (High-intelligence fallback)
  3. @cf/meta/llama-3.2-3b-instruct (Lightweight fallback)
  4. @cf/mistral/mistral-7b-instruct-v0.2-lora (External fallback)
